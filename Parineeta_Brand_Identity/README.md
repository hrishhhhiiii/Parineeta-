*এ যেন এক বিয়ের মরশুম* (A season of weddings)

Start with **`00_Brand_Guidelines/Parineeta_Brand_Guidelines.pdf`**: the 16-page brand book.

| Folder | What's inside |
|---|---|
| `00_Brand_Guidelines` | Brand book (PDF + HTML source) |
| `01_Primary_Emblem` | Full-colour + reverse emblem: SVG, print-ready vector PDF, transparent PNG |
| `02_Lockups` | Horizontal, stacked, wordmark ± tagline: full colour + reverse |
| `03_Monogram_and_Seal` | প + paan-leaf monogram, circular seal |
| `04_One_Colour` | Black / white / crimson / gold: every logo, for foil, emboss, newsprint, laser |

| `_build` | Python source that regenerates everything (`python build_all.py`, then `python guidelines.py`) |

## Formats
- **SVG**: web and anything that scales. **PDF**: vector, for printers and sign makers. **PNG**: transparent, for documents and social.
- All text in every logo is **converted to outlines**; no fonts need installing to use the logos.

## Brand basics
- Colours: Rajwadi Crimson `#4D050C` · Sindoor Red `#C01E2E` · Zari Gold `#C8922A` · Marigold `#F2B632` · Champagne `#F3DC9A` · Ivory `#FAF5E8` · Deep Zari `#8A5A0B`
- Fonts (all SIL OFL, free on Google Fonts): Noto Serif Bengali, Cinzel, Cormorant Garamond, Hind Siliguri

## Things to confirm with the client before final print
- CMYK values are starting points, not spot-colour matches; run a press proof.
- Business card / letterhead contact details are placeholders.
- The brand-essence copy (personality, voice) is an informed proposal; confirm it fits how the client describes themselves.
- The older raster-based files in the parent folder (`01_Primary_Crest` … `10_…`, `website/`) are untouched.
